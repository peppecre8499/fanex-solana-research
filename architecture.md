# Architecture Notes

## Basic Flow

1. Creator revenue is verified off-chain.
2. A revenue-linked asset is represented digitally.
3. Users interact through wallets.
4. Settlement can be tested with stablecoin logic.
5. Distribution rules can be automated after verification.

## Open Questions

- Best stablecoin standard
- Regulatory constraints
- Custody vs non-custody architecture
- Secondary market liquidity
- Oracle and verification model

## Devnet Scope

The current implementation focus is limited to devnet testing.

Mainnet deployment requires additional legal, security and infrastructure review.
